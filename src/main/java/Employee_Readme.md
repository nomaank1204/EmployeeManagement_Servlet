Employee Management System (Servlet + JDBC)
📌 Project Description

This is a simple Employee Management System built using:

Jakarta Servlet (Jakarta EE)

JDBC

HTML (generated inside Servlet)

MySQL (or any JDBC-supported database)

The application allows users to:

Add employee details

Store employee data into a database

🛠 Technologies Used

Java (JDK 17+ recommended)

Jakarta Servlet API

JDBC

MySQL Database

Apache Tomcat (10+ recommended for Jakarta)
